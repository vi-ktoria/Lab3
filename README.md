# Лабораторная работа № 3 — Доска публикаций

## Запуск
Откройте `index.html` в современном браузере. Установка дополнительных программ не требуется.

## Реализованные функции
- GET-запрос к `https://jsonplaceholder.typicode.com/posts?_limit=5` загружает и отображает пять публикаций.
- Пустые поля и поля, содержащие только пробелы, не отправляются; отображается сообщение об ошибке.
- POST-запрос отправляет `title`, `body` в формате JSON. После успешного ответа отображаются заголовок и ID созданной публикации.
- Во время запросов отображается статус, соответствующая кнопка блокируется и повторно активируется после завершения.
- Сетевые ошибки и неуспешные HTTP-ответы обрабатываются через `try/catch/finally` и `response.ok`.
